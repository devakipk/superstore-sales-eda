# superstore-sales-eda
This repository include projects based on data analysis

Sales Analysis Project 📊

Project Title

Exploratory Data Analysis (EDA) on Superstore Sales Data

Project Description

This project focuses on analyzing Superstore sales data using Python to understand sales performance, profit trends, customer segments, and regional business performance.

The project includes data exploration, data cleaning, data visualization, outlier detection, and business insights to support data-driven decision-making.

Project Objective

- Analyze sales and profit trends.
- Compare sales performance across product categories and regions.
- Identify high-performing and low-performing categories.
- Analyze customer segments and sub-categories.
- Detect outliers in sales, profit, and discount.
- Generate meaningful business insights.

Dataset

- Superstore Sales Dataset
- Format: Excel (.xlsx)

Technologies Used

- Python
- Google Colab
- NumPy
- Pandas
- Matplotlib
- Seaborn

Project Workflow

1. Data Loading
2. Data Exploration
3. Data Cleaning
4. Data Visualization
5. Outlier Detection using IQR
6. Business Insights
7. Conclusion

Features

- Missing Value Analysis
- Duplicate Record Detection
- Sales Analysis by Category and Sub-Category
- Sales Analysis by Customer Segment
- Regional Sales Analysis
- Top 5 Cities by Sales
- Sales, Profit, Quantity, and Discount Distribution
- Correlation Heatmap
- Sales vs Profit Analysis
- Discount vs Sales Analysis
- Outlier Detection using IQR
- Category-wise Sales Comparison
- Region-wise Profit Comparison
- Sub-Category-wise Profit Analysis
- Overall Profit Margin Calculation

Key Insights

- Identified the highest and lowest sales-generating categories.
- Analyzed regional profit performance.
- Identified the highest and lowest profit-generating sub-categories.
- Calculated the overall profit margin of approximately 12.47%.
- Analyzed sales, profit, and discount distributions.
- Identified potential outliers in numerical variables.

How to Run

1. Download the project notebook.
2. Open it in Google Colab.
3. Upload the Superstore dataset.
4. Run all notebook cells.
5. Explore the analysis results and visualizations.

Conclusion

This project helped analyze Superstore sales data and identify important sales and profit patterns using Exploratory Data Analysis.

The analysis provides useful business insights that can support better understanding of sales performance and profitability.
